
# Student Profile Team

## About the Project
This project is a shared student profile repository
created using HTML, Git and GitHub.

## Team Members

| Name | Role |
|---|---|
| Student 1 | Team Lead |
| Student 2 | Profile Developer |
| Student 3 | Skills Developer |
| Student 4 | Contact Developer |

## Project Files

- profile.html - Student profile information
- skills.html - Student skills and hobbies
- contact.html - Contact information

## Technologies Used
- HTML
- Git
- GitHub

## Purpose
To learn collaborative development using Git branches,
commits and Pull Requests.
